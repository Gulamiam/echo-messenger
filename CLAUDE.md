# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Рабочий язык репозитория — русский: комментарии в коде, документация и UI-тексты пишутся по-русски.

«Эхо» — учебный мессенджер на Next.js: личные чаты и группы, регистрация и вход по почте и паролю (писем не отправляем, почта не подтверждается), приглашения в группу по ссылке, фото в сообщениях. Новые сообщения приходят без перезагрузки страницы, а своё сообщение показывается сразу, ещё до ответа сервера (оптимистичная отправка со статусом `sending` → `sent` / `failed`).

Проект на ранней стадии: готовы лендинг (`app/(marketing)/`), дизайн-токены и модели данных; большинство файлов маршрутов, API, `auth.ts` и `db/` заведены пустыми — это намеченная структура, а не забытый мусор. Пустой файл заполняется по месту, а не переносится.

## Устройство

| Где | Что |
| --- | --- |
| `app/(marketing)/` | лендинг, `demo-chat.ts` — демо-переписка для него |
| `app/(auth)/` | регистрация (`register`), вход, онбординг (выбор ника) |
| `app/(app)/chats/` | список чатов в `layout.tsx` (живёт, пока меняется только `[chatId]`), лента — `[chatId]/page.tsx`, создание чата — перехватывающий маршрут в слоте `@modal` |
| `app/api/auth/` | Better Auth (`[...all]`), отправка сообщений, поток новых сообщений (`stream`), загрузка фото |
| `app/invite/[code]/` | приглашение в группу с OG-картинкой |
| `lib/types/types.ts` | формы данных: `User`, `Chat`, `Message`, `ChatPreview` и др. |
| `lib/models/` | модели для UI (`MessageModel`) — то, что получает компонент, а не строка из БД |
| `components/` | общие компоненты, каждый в своей папке со своим `.scss` |
| `db/` | схема, подключение и сид |
| [proxy.ts](proxy.ts) | пускает в `/chats`, `/settings`, `/onboarding` только с сессией Better Auth, иначе ведёт на `/login?callbackUrl=…` |

## Главное правило: код пишется для людей

Код читается в десятки раз чаще, чем пишется. Оптимизируйте под читаемость: если коллега, незнакомый с модулем, поймёт код за разумное время — решение верное.

- **Простое решение предпочтительнее сложного.** Без паттернов и абстракций там, где хватает прямолинейного кода — проект учебный, его должен понимать middle.
- **Явное лучше неявного** — никаких скрытых побочных эффектов.
- **Комментарий объясняет «почему»**, код — «что» и «как». Если без комментария непонятно, что делает функция, меняйте имя.
- **Согласованность важнее личных предпочтений.** Новый код пишется в стиле окружающего.\
- **Новая функция в functions сопровождается тестом**

## Команды

```
npm run dev      # dev-сервер Next (http://localhost:3000)
npm run build    # продакшен-сборка
npm run start    # запуск собранного
npm run lint     # eslint (конфиги next/core-web-vitals и next/typescript)
npm test         # юнит-тесты lib/**/*.test.ts (встроенный node:test через tsx)
```

Юнит-тесты лежат рядом с модулем (`lib/format.test.ts`). Папка `e2e/` заведена под будущие e2e-тесты, раннер для них не настроен. Изменения в UI проверяются в браузере через `npm run dev`.

## Конвенции

- **Вёрстка — БЭМ на SCSS**, классы глобальные: `block`, `block__element`, модификатор `block_mod` (`message_mine`). Файл `*.module.scss` импортируется как обычный (`import './page.module.scss'`), без объекта `styles`. Условные классы — через `clsx`. Tailwind подключён, но новые стили на нём не пишутся.
- **Цвета только через токены** из [app/globals.css](app/globals.css) (`--color-*`, `--avatar-1…6`), не литералами: у каждого токена подписано назначение — берите подходящий по смыслу. Иконки — классы `ico-*` из [lib/icons.scss](lib/icons.scss), кнопки — `echo-button` с размером и видом (`size_l primary`).
- **Прокрутка — через [ScrollArea](components/ScrollArea.tsx)** (OverlayScrollbars + Lenis), не через нативный `overflow` с самодельным скроллбаром.
- **Типы данных — в `lib/types/types.ts`.** id пользователей и чатов — строки (`UserId`, `ChatId`), id сообщения — число (bigserial, по нему курсоры). Даты — ISO-строки в UTC. У `Attachment` обязательны `width` / `height`: без них `next/image` сдвигает ленту.
- Импорты из корня — через алиас `@/`.
- Коммиты и пуш делает человек.
